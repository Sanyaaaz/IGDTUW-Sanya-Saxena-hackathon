# Three-minute judge demo

Use the seeded **Major Middle East oil supply disruption** event. It is explicitly synthetic and has zero verified live source corroboration; the purpose is to demonstrate the full calculation path without pretending to have live news evidence.

1. **0:00–0:25 · Command center.** Point out the ₹100 Cr synthetic portfolio, high-impact event count and the emerging event-risk clusters. State that there is no long-run baseline and no live article claim in this fixture.
2. **0:25–1:00 · Event analysis.** Open the oil-disruption event. Show its event classification and keyword evidence, negative lexical sentiment, synthetic provenance, zero independent sources, normalized Middle East/Oil entities, and mapped portfolio exposures. Emphasize that classification strength is not a calibrated probability.
3. **1:00–1:35 · Transmission.** Walk through event → crude oil, inflation, rates and credit spreads → asset sensitivities. Call out Airline Corp's negative crude-oil sensitivity, the positive energy-index hedge and the long-duration bond's rate exposure. Explain that edges are deterministic configured rules.
4. **1:35–2:05 · Scenario assumptions.** Choose **SEVERE**, generate the editable event scenario and read out the implied factor shocks. Label every value “model-implied stress assumption, not a forecast.” Adjust one factor shock to demonstrate analyst control.
5. **2:05–2:40 · Run impact.** Run What-If. Show portfolio baseline, stressed value, P&L, loss percentage and the asset rows. Identify the largest loser and hedge using the computed returns.
6. **2:40–3:00 · Close on provenance.** Open Data & Model Status. Show each provider's configured flag, last successful fetch, last error and ingested count. Explain that `LIVE` is assigned only after a successful provider response; demo inputs are synthetic, analyst input is fallback, and model results remain inferred.
